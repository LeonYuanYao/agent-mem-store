# Dreaming：Terra 与 Luna 的固定输入对照实验

> 公开版说明：项目名称、样本身份及私有仓库引用已匿名化，业务例子已泛化；实验汇总指标和结论保持原样。本次脱敏没有重新运行实验，私有输入不随仓库发布。sample-* 是报告专用别名，不能用于查询真实记忆。

日期：2026-09-10。范围：离线实验；未修改正式记忆、运行配置或治理任务。

## 结论

Terra Low 连续三次正确拒绝了 Luna Medium 上一轮误判的替换，但在另一对记忆上提出了未完整保留明确限制的替换。此次没有得到可接受的真实记忆缩减，因此暂不建议仅靠更换模型推进自动 Dreaming。

这说明 Terra 在某些细节判断上有改善，尚不能证明整体质量更高或已达到自动执行标准。当前验证的是保留现有原文的重复项识别，不覆盖重新撰写综合知识的完整 Dreaming 能力。

## 方法

- 复用上一轮冻结的 21 条单项目真实记忆；排除 Human-authored 和 review_due 后，17 条参与候选生成。
- 对照包含 3 个自动邻域、3 对最高相似度记忆，以及 1 个人工构造的逐字重复正例。正例不计入真实收益。
- 7 个对应请求的业务输入 SHA-256 全部一致，提示词和输出 schema 不变。
- Luna 使用 `gpt-5.6-luna` / Medium；Terra 使用 `gpt-5.6-terra` / Low。两者均为 default service tier，未开启 fast。
- Terra 另对上一轮失败的 pair-3 重复调用两次，共 9 次调用。所有调用正常完成，结构、ID、引用原文检查均通过。
- 模型只能建议保留某条现有记忆并移除重复项，不能重写原文。主 Agent 根据原文审核语义；审核预期在查看 Terra 输出前记录。

## 结果

| 输入 | Luna Medium | Terra Low | 主 Agent 复核 |
|---|---|---|---|
| 3 个自动邻域 | 全部不替换 | 全部不替换 | 各条包含独立条件，保留合理 |
| pair-1：sample-16 / sample-19 | 不替换 | 不替换，指出 abort 限定差异 | 预先认为可能可缩减，但措辞确有歧义，不将此项计为确定错误 |
| pair-2：sample-16 / sample-21 | 不替换 | 保留 sample-16，移除 sample-21 | 不接受：明确的批量解决限制没有完整保留 |
| pair-3：sample-19 / sample-21 | 保留 sample-21，移除 sample-19 | 不替换；额外两次也不替换 | Terra 正确识别分析与向用户说明的差异 |
| 合成逐字重复正例 | 正确识别 | 正确识别 | 仅证明能够提出重复项建议 |

pair-2 的原文 sample-21 明确提到不得用 `--ours/--theirs` 等批量解决。Terra 将它映射到 sample-16 的“未经批准解决”，但后者没有同样明确的手段限制。即使把两个表述理解为相近，它们在批准后的适用范围仍有歧义，不能据此自动移除原记忆。Terra 在 pair-3 中能指出这条限制，在 pair-2 中却把它视为已覆盖，表明判断仍受搭配影响。

pair-1 的预先审核认为 sample-16 可能覆盖 sample-19。Terra 指出“自动 abort”和“不 abort / 不得擅自中止”存在限定差异。该项保留原预期记录并标记为有歧义，避免根据模型输出修改标准后计算漂亮的准确率。

两模型各提出 1 个真实替换建议，复核均未接受。真实样本仍为 21 条，没有构造新的检索快照或声称检索收益。

## 用量与耗时

以下只比较相同的 7 个请求；输出 token 包含 reasoning 部分，不重复相加。

| 指标 | Luna Medium | Terra Low |
|---|---:|---:|
| 输入 token | 77,685 | 88,290 |
| 缓存输入 token（输入的子集） | 0 | 15,872 |
| 输出 token | 3,530 | 2,490 |
| reasoning output token | 2,174 | 1,320 |
| 调用累计耗时 | 115.4 秒 | 99.7 秒 |

Terra 的额外两次复测消耗输入 23,760、输出 484 token，累计 27.4 秒。9 次合计输入 112,050、输出 2,974 token。业务输入一致不代表模型端输入 token 相同；这些数字也不能直接换算成相同价格或稳定的速度优势。

## 下一步建议与限制

保留当前实验边界，不启用自动替换。若继续验证，优先把比较要求细化为逐条检查触发条件、禁止行为、批准条件和例外，要求明确指出仍未覆盖的原文；用固定的可合并与不可合并样本一起复测，避免靠全部拒绝获得表面安全性。暂不增加多模型流水线。

样本是已经研究过的小型开发集，组合存在重叠；审核由主 Agent 完成，没有独立人工标注，也没有重开源会话核实历史知识本身。Terra Low 与 Luna Medium 是配置对比，不能将差异全部归因于模型智能度。两次额外复测只覆盖 pair-3，不代表所有输入的稳定性。
