# Store distilled knowledge instead of transcripts

Memory Vault stores distilled, reusable knowledge rather than copies of complete Agent sessions. Source sessions remain in each Agent's native history system, while every extracted memory retains enough provenance to locate its source. This limits retrieval noise and long-term cleanup cost without giving up traceability.

Unverified conclusions may enter the vault only as explicitly unverified Memory Candidates; they must not be represented as established facts or participate in normal recall as Durable Memories. Importing a complete session is an explicit archival action, not the default capture path.
