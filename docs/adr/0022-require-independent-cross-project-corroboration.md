# Require independent cross-project corroboration

Automatic Global promotion requires materially agreeing support from at least two distinct `project_id` values. Multiple sessions inside one Project do not add independence, and multiple worktrees or clones that share a Project Marker count as one Project. A path, checkout, or session count is not a substitute for Project identity.

Each project-level source must independently originate from traceable user input, code, command output, or external evidence and must satisfy the ordinary promotion conditions. Evidence does not become independent merely because the same upstream assertion appears in different Projects. Automatic corroboration applies only to Normal content; Private content still needs an explicit human Global directive, and Secret Content remains prohibited.

MemStore records the bounded Memory identities injected into a source context, or a reference to its Injection Receipt, in Capture Event or candidate provenance. A later conclusion that depends on an injected Memory is a Memory Echo. It may retain that dependency for diagnosis but cannot increase the corroboration count, confidence, or authority of the original claim. This prevents MemStore from manufacturing apparent consensus by injecting and re-extracting its own output.

Corroborating claims must agree in core statement, applicability conditions, and certainty rather than merely sharing keywords. Any material Project or Global conflict blocks automatic promotion. If project-specific conditions differ, Luna may propose only the supported intersection as a new Agent-derived Global Candidate; it cannot generalize beyond the shared evidence.

The Global Candidate receives its own identity and cross-project provenance and follows the ordinary candidate lifecycle. Source Project Memories keep their identities, scopes, and provenance. An explicit user Global directive bypasses the two-project count but not sensitivity containment, conflict handling, provenance, or the distinction between Direct Human Assertion and Model-derived Extraction.
